# IVOL Bar

**Скрывай среднюю группу значков, оставляя важное по обе стороны.**

[English documentation](README.md) · [Скачать](https://github.com/oiv-an/IVOLBar/releases/latest) · [Сообщить о проблеме](https://github.com/oiv-an/IVOLBar/issues) · [Лицензия MIT](LICENSE)

IVOL Bar — небольшая открытая утилита для строки меню macOS. Написана на Swift и Objective-C с AppKit. Значки остаются в настоящей строке меню: расставьте их обычным перетаскиванием с Command и скрывайте группу между двумя границами.

```text
Всегда видно    │    Скрываемые значки    ‹    Всегда видно
```

> **Экспериментальная версия: macOS 27, Apple Silicon.** Проверена на macOS 27.0.1, arm64. Используется недокументированный механизм Apple, который может измениться после обновления системы. Первый релиз подписан ad-hoc, **без Developer ID и нотарификации Apple**. Это не приложение из App Store.

## Возможности

- Скрытие средней группы между полоской и стрелкой; обе внешние группы остаются видимыми.
- Ручное скрытие и раскрытие нажатием стрелки.
- Автоскрытие после ухода мыши с задержкой 3, 5, 10 или 30 секунд.
- Настоящие значки строки меню, без отдельной панели-замены.
- Без аккаунта, сетевого сервиса, аналитики и сторонних пакетных зависимостей.
- Локальная диагностика; при завершении приложения ограничение видимости снимается.

## Требования

|                | Требование                                                                |
| -------------- | ------------------------------------------------------------------------- |
| Система        | macOS 27 и новее; фактически проверена только 27.0.1                      |
| Готовая сборка | Apple Silicon / arm64; Intel не проверен, сборки для него нет             |
| Разрешение     | Управление интерфейсом / Accessibility для чтения расположения значков    |
| Сборка         | Xcode Command Line Tools с SDK macOS 27, Swift 6.4, Clang, Python 3 и zsh |

Предыдущие macOS не поддерживаются. Проверка доступности приватного механизма при запуске не гарантирует совместимость с будущими версиями системы.

## Установка готовой версии

1. В разделе [Releases](https://github.com/oiv-an/IVOLBar/releases/latest) скачайте `IVOL-Bar-0.1.3-macos-arm64.zip` и `SHA256SUMS.txt`.
2. При необходимости проверьте архив командой из папки загрузки:

   ```sh
   shasum -a 256 -c SHA256SUMS.txt
   ```

3. Распакуйте архив и перенесите **IVOL Bar.app** в **Программы / Applications**. Не запускайте его прямо из архива и не держите несколько работающих копий.
4. Откройте приложение. Релиз не нотарифицирован, поэтому macOS может заблокировать первый запуск. Если доверяете источнику, используйте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**, когда система предлагает такую возможность, и подтвердите запуск. **Не отключайте Gatekeeper целиком.** Если политика вашего Mac запрещает такой запуск, используйте сборку из исходников.
5. По запросу разрешите **IVOL Bar** управление интерфейсом в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ / Accessibility**. Название раздела зависит от версии и языка macOS. Если стрелка сообщает об отсутствии разрешения, включите его там и повторите нажатие.
6. Расставьте границы и значки по инструкции ниже. **В новом профиле автоскрытие изначально выключено**, чтобы не мешать расстановке. Включите его через меню после настройки.

Установщик, скрипт с правами администратора и фоновый агент не требуются. Автозапуск не добавляется автоматически. При необходимости добавьте приложение самостоятельно через **Системные настройки → Основные → Объекты входа**.

## Сборка из исходников

При необходимости установите инструменты Apple:

```sh
xcode-select --install
```

Проверьте, что выбранный набор инструментов содержит SDK macOS 27 и Swift 6.4:

```sh
xcrun --show-sdk-version
xcrun swiftc --version
```

Затем клонируйте и соберите:

```sh
git clone https://github.com/oiv-an/IVOLBar.git
cd IVOLBar
/bin/zsh build.sh
```

Результат — `build/IVOL Bar.app`. Скрипт компилирует исходники, создаёт приложение, **по умолчанию подписывает ad-hoc** и проверяет подпись. Он не устанавливает и не запускает приложение, не меняет настройки и не запрашивает разрешения. Homebrew, Swift-пакеты и проект Xcode не нужны.

### Установка своей сборки

Перед заменой завершите работающий IVOL Bar через его меню. Затем из папки проекта:

```sh
ditto 'build/IVOL Bar.app' '/Applications/IVOL Bar.app'
open '/Applications/IVOL Bar.app'
```

Если у вашей учётной записи нет прав на запись в Applications, используйте обычное подтверждение Finder, не меняйте разрешения папки.

### Подпись и отдельная папка сборки

Для стабильной локальной подписи можно указать уже существующий сертификат из Связки ключей:

```sh
IVOL_SIGN_IDENTITY='Your Code Signing Identity' /bin/zsh build.sh
```

Чтобы не затрагивать другие локальные сборки:

```sh
IVOL_BUILD_DIR="$PWD/build/custom" /bin/zsh build.sh
```

Самоподписанный сертификат разработчика **не делает** скачанное приложение доверенным на чужом Mac. Публичное распространение с Developer ID требует подходящего сертификата Apple, соответствующих параметров подписи и отдельной нотарификации; этот проект её не автоматизирует. Не добавляйте ключи и сертификаты в Git. Смена подписи и обновление ad-hoc-сборки могут потребовать повторного разрешения Accessibility.

### Подготовка релизного архива

На Mac с Apple Silicon и нужным набором инструментов:

```sh
/bin/zsh scripts/package-release.sh
```

Скрипт создаёт свежую ad-hoc-сборку, ZIP и SHA-256 в `dist/0.1.3/`. Ничего не устанавливает и не отправляет на сервер. Для сопровождающих есть [чек-лист выпуска](docs/RELEASING.md).

## Управление

Перед изменением состава откройте меню → **Настроить группу по расположению…**. Автоскрытие приостановится до сохранения или отмены.

1. Зажмите **⌘ Command** и перетащите полоску **│** левее стрелки **‹**.
2. Переместите скрываемые значки **между** полоской и стрелкой.
3. Важные значки оставьте снаружи с любой стороны.
4. В меню выберите **Сохранить группу по расположению**. Затем нажимайте стрелку для скрытия или раскрытия сохранённой группы. В скрытом состоянии направление стрелки меняется.
5. Нажатие полоски или правая кнопка по стрелке открывает меню:
   - **Показать всё** — раскрыть группу.
   - **Автоскрытие после ухода мыши** — включить или выключить автоскрытие.
   - **Задержка** — 3, 5, 10 или 30 секунд; по умолчанию 5.
   - **Как пользоваться** — краткая инструкция.
   - **Открыть диагностику** — локальный журнал.
   - **Завершить IVOL Bar** — снять ограничение и закрыть приложение.

Интерфейс приложения сейчас русскоязычный.

Автоскрытие откладывается, пока указатель находится в строке меню, удерживается кнопка мыши или Command либо открыто собственное меню IVOL Bar. Простое наведение не раскрывает группу. При ошибке настройка не выключается: автоматический повтор откладывается минимум на 30 секунд, ручное нажатие доступно сразу.

Завершение и повторный запуск уже известных приложений не раскрывают группу. Новое неизвестное приложение, сон/пробуждение или изменение дисплеев снимают ограничение для безопасности; после стабилизации экранов автоскрытие использует сохранённую группу, а не новые координаты. Состав хранится между перезапусками; новое приложение не добавляется в него автоматически. Переменная `IVOLBAR_DIAGNOSTIC=1` специально раскрывает группу через пять секунд — не используйте её при обычном запуске.

## Принцип работы и ограничения

Через Accessibility считывается расположение элементов, размещённых системным MenuBarAgent. Границы выбираются из одной строки меню. Приватный механизм assessment mode в MenuBarClientCore разрешает приложения снаружи и ограничивает приложения внутри группы.

Важные ограничения:

- **Скрытие действует на приложение, а не на отдельный значок.** Если при сохранении группы значков несколько и хотя бы один снаружи, приложение остаётся разрешённым.
- Для системных элементов запрашивается сохранение видимости, но поведение приватного механизма может отличаться между версиями macOS.
- Обновления, смена пути и дубли других приложений не блокируют сворачивание всей группы. Состав сохраняется по идентификаторам приложений, без привязки к пути установки. Геометрия используется только при первоначальном выборе и явном сохранении новой группы; сон и перемещение границ системой не меняют состав. Однако macOS может скрыть конфликтующую копию даже вне группы. Раскройте группу стрелкой для доступа к такому элементу. Перетаскивание задаёт новую позицию, но само по себе не гарантирует устранение системного конфликта копий.
- Совместимость не универсальна: у некоторых утилит наблюдалось неожиданное исчезновение значков, в том числе у noTunes. Сначала проверьте собственную расстановку; не полагайтесь на видимость критичного управления без проверки.
- Независимая настройка дисплеев не поддерживается. При настройке выбирается валидная пара границ с наибольшим промежутком. Сохранённая группа общая для всех дисплеев. IVOL Bar не восстанавливает физический порядок значков macOS; он сохраняет выбранный состав скрытия. Вырез экрана и нестандартная конфигурация мониторов могут мешать определению группы.
- Собственное открытое меню защищено от автоскрытия; для произвольных меню других приложений такой гарантии нет.
- Успешный системный ответ и наличие Accessibility-элементов не доказывают видимость значков. После установки и обновления macOS проверяйте результат глазами.

**Показать всё** или завершение IVOL Bar снимают его ограничение. При диагностике не запускайте одновременно несколько утилит скрытия строки меню.

## Решение проблем

| Проблема                            | Что проверить                                                                                                           |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Ничего не скрывается                | Разрешение Accessibility, полоска левее стрелки, сторонние значки между ними, последняя ошибка в меню                   |
| Автоскрытие не срабатывает          | Включить его в меню, убрать указатель, отпустить мышь и Command, закрыть собственное меню, дождаться задержки           |
| Пропали важные значки               | «Показать всё» или завершить приложение; проверить дубли установок и ограничения совместимости                          |
| Разрешение пропало после обновления | Сохранять путь и подпись; при необходимости повторно разрешить Accessibility в системных настройках                     |
| После переноса не собирается        | Проверить выбранный SDK и компилятор; использовать свежую выходную папку, поскольку кэш может содержать абсолютные пути |
| macOS блокирует скачанную версию    | Учесть отсутствие нотарификации; разрешать конкретное приложение только при доверии к нему или собрать локально         |

Журнал находится в пользовательской папке **Library/Logs/IVOLBar.log**. Домен настроек — `pro.ivol.bar`; расположением значков управляют macOS и соответствующие приложения. Журнал может содержать названия программ, пути и координаты. **Удаляйте личные данные перед публикацией диагностики в issue.** Приложение никуда не отправляет журнал.

## Обновление и удаление

**Обновление:** завершите IVOL Bar, замените его в Applications новой версией и запустите. Не удаляйте настройки и не расставляйте значки заново. Сохраняйте путь установки. При смене подписи может понадобиться повторное разрешение Accessibility. Для отката можно заранее сохранить предыдущую копию приложения.

**Удаление:** завершите IVOL Bar и перенесите его из Applications в Корзину. Если самостоятельно добавляли объект входа, удалите его там. Локальные настройки и журнал намеренно остаются; позиции значков других приложений не сбрасываются.
